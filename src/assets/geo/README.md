# countries-50m.json

Country shapes used as the map background, so maps work without any tile server.

- Source: Natural Earth, `ne_50m_admin_0_countries.geojson`
  (https://github.com/nvkelso/natural-earth-vector), public domain.
- Reduced: properties removed, coordinates rounded to 0.01° (about 1 km).

For street-level detail, replace this layer with a local PMTiles file.
